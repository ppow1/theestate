# Magnetic Pogo-Connector Capability Narrative

Status: Validation example for the proposed lifecycle; not an implementation claim.

## Grace decomposition

For “Design a magnetic pogo connector that fits an existing Estate product
design,” Grace records a generic objective and decomposes required capabilities:
existing design retrieval, dimensional inspection, calibrated image measurement,
spatial reasoning, CAD modification, mechanical fit analysis, material
recommendation, prototype generation, production-material recommendation, STL or
CAD artifact generation, documentation, and a physical test plan.

Grace does not select an adapter. Helen evaluates each capability against
authoritative worker, qualification, health, availability, and authorization
evidence. Missing capability evidence creates a gap and may lead to an advisory
Engineering worker specification and a separate enabling project.

## Measurement provenance

Measurements retrieved from existing CAD are CAD-derived. Measurements supplied
by the Steward are declared inputs. Measurements inferred from an image are only
usable as dimensional evidence when the image has a known scale or calibration
reference; image-only visual inference must not be represented as exact. All
assumptions requiring physical verification remain explicit acceptance criteria.

## Example acceptance evidence

The enabling or original project must identify the source and uncertainty of
each dimension, fit and clearance analysis, material recommendation, generated
STL/CAD artifact, documentation artifact, and physical test plan. A generated
PLA prototype and PETG production recommendation are claims to validate against
the commission, not defaults. Engineering validation does not replace Steward
or Chief Architect acceptance where those authorities apply.
