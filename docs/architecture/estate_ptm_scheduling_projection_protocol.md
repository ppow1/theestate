# Estate PTM Scheduling Projection Protocol

Scheduling projections must report active execution time, validation time, expected rework, integration time, queue wait, human/Steward review wait, blocked dependency wait, total machine-active time, and expected wall-clock elapsed time. Estimates use best, expected, conservative ranges, confidence, and basis. Days may appear only as secondary wall-clock conversions when external waits justify them. Packages over 15 expected active minutes are flagged for review; packages over 60 minutes require evidence-based exception.
