## Git-authoritative correspondence

The worktree path is obtained from `git status --porcelain`; rename
correspondence is separately obtained from `git status --find-renames=20%`.
For committed reconciliation, `_git_rename_pairs` obtains old/new pairs from
`git diff --name-status --find-renames=20%` between the approved base and
resulting commit.

`validate_observed_state` receives the authoritative pair generated by those
paths. Provider changed-path claims are compared to Git-observed changed paths
and cannot introduce a rename pair. A claimed pair absent from the actual
changed set is rejected by `_outside_scope`.
