
GitHub Transport Adapter v1

Status: Initial Shared Transport Adapter

1. Purpose

GitHub is the first shared transport implementation for the Estate Communication Bus.

GitHub is not the Communication Bus.

GitHub provides versioned collaboration and shared institutional state after promotion approval.

2. Responsibilities

The GitHub adapter supports:

Published work packages.
Shared institutional documents.
Standards.
Architecture.
Review workflow.
Commit history.
Future issue and pull request integration.
Future project board integration.
3. Non-Responsibilities

GitHub does not own:

The Communication Bus.
Privacy classification.
Boundary approval.
Pat's private artifacts.
Local runtime state.
Generated media by default.
Prompts or prompt history by default.
Intermediate artifacts by default.
4. Shared Paths

Potential GitHub-shared paths:

collaboration/messages
collaboration/work_packages
collaboration/promotions
collaboration/status
docs/collaboration
docs/governance
5. Safety Checklist

Before pushing to GitHub:

Confirm classification.
Confirm promotion approval.
Confirm no Local Only artifacts are included.
Run audit.
Confirm git status.
Commit with EC identifier when appropriate.
6. Future GitHub Use

Future GitHub integration may include:

Issues as work package surfaces.
Pull requests as review workflow.
GitHub Actions as audit runners.
Project boards as task boards.
Labels as routing metadata.

These are not required for v1.
