
Message Type Definitions v1

Status: Message Type Reference

work_package

A bounded assignment with mission, scope, boundaries, required reading, deliverables, and acceptance criteria.

directive

An instruction from an authorized participant.

request

A request for action, information, review, routing, or approval.

response

A reply to a request or directive.

status

A report of current state.

notification

A non-blocking message intended to inform participants.

event

A recorded occurrence in the collaboration system.

escalation

A message that moves unresolved responsibility upward.

approval

A decision allowing a proposed action.

audit_record

A record of validation, failure, or audit evidence.

promotion_request

A request to move information from local/private state into shared institutional state.

promotion_decision

Approval or rejection of a promotion request.
