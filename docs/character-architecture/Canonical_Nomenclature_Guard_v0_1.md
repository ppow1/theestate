# Canonical Nomenclature Guard v0.1

This guard records a small set of dictation-sensitive Estate names that must remain canonical in resident and Character Architecture artifacts. It is not a broad terminology registry.

## CueMastery

- Canonical spelling: CueMastery
- Pronunciation aid: cue mastery
- Allowed lowercase machine identifier: `cuemastery`
- Forbidden dictation or misheard variants:
  - Qmaster
  - qmaster
  - Q Master
  - Q mastery
  - Q Mastery
  - queue mastery
  - Queue Mastery
  - QueueMastery
  - Cue Mastery
  - CUEMASTERY
- Usage rule: Use CueMastery in prose, headings, titles, resident artifacts, Character Architecture artifacts, workstream names, and user-facing documents. Use `cuemastery` only for lowercase machine identifiers such as JSON fields, snake_case identifiers, filenames, or URLs.

## IONOGE

- Canonical spelling: IONOGE
- Pronunciation aid: eye-oh-no-gee
- Allowed lowercase machine identifier: `ionoge`
- Forbidden dictation or misheard variants:
  - Ionoge
  - ion oge
  - ion-oge
  - Iono Gee
  - IonoGee
  - Ionogy
  - Eyeonoge
  - Eye Oh No Gee
  - Eye-Oh-No-Gee
- Usage rule: Use IONOGE in prose, headings, titles, resident artifacts, Character Architecture artifacts, workstream names, and user-facing documents. Use `ionoge` only for lowercase machine identifiers such as repository names, hostnames, JSON fields, snake_case identifiers, filenames, or URLs.
