# Office Personnel Directory and Org Chart Control Surface

WP-0514 adds a read-only Office personnel control surface backed by canonical Estate artifacts.

## Canonical Sources

The personnel payload is generated by `estate.core.office_personnel_directory` from:

- `data/registry/personnel.json`
- `data/registry/mailboxes.json`
- `data/registry/residents.json` when present
- worker registry/runtime artifacts when present
- `collaboration/messages` through the mailbox index
- `collaboration/work_packages` through the assignment queue
- capability/dependency artifacts through the existing capability visualization

No new personnel registry, mailbox system, or org-chart database is introduced. The runtime JSON at `runtime/steward/office_personnel_directory.json` is a generated Office projection only.

## Controls

The Personnel tab supports:

- employee row/card/name/org-node open to the same detail drawer;
- direct employee deep links with stable `employee_id` in the URL hash;
- Enter to open focused rows/nodes and Escape to close the detail drawer;
- manager and direct-report navigation;
- office org nodes filtering the directory;
- search by name, title, employee ID, mailbox ID, office, and capability;
- filters for office, status, and worker/resident classification;
- deterministic sort by name, role, office, status, or employee ID;
- copy controls for employee ID and mailbox ID;
- mailbox and conversation routes when canonical identifiers are available;
- truthful blocked states for missing mailbox/conversation capabilities;
- refresh through `personnel.refresh`.

## Detail Contract

The detail drawer displays indexed values for employee ID, mailbox ID, display name, title, office, classification, manager, direct reports, status, assignments, capabilities, dependencies, mailbox path/attention summary, resident/worker profile paths, related work packages, operational evidence, source artifact references, refresh timestamp, and warnings. Missing data is labeled unavailable rather than fabricated.

## Structural Validation

Refresh detects and surfaces duplicate employee IDs, orphaned manager references, manager cycles, disconnected nodes, malformed records, and missing source artifacts. Malformed records are counted and kept visible as warnings; they are not silently discarded.
