# Readiness Checklist

- [ ] Notebook JSON validates against the closed schema.
- [ ] Objective, stage, scope, authority, blocker, and required validation are current.
- [ ] Source commit and relevant digests match authoritative records.
- [ ] Worker acknowledgment matches the packet exactly.
- [ ] Proposed changes have observed or validator provenance.
- [ ] No secret, absolute path, parent traversal, or chain-of-thought is stored.
- [ ] Required tests, schema, compilation, and fixture-integrity checks pass.
- [ ] Receipts and reconciliation references exist where execution occurred.
- [ ] Stale/conflicted state fails closed.
- [ ] Institutional acceptance remains separate and not granted.
- [ ] Handoff omits transcript history and records explicit safe facts/omissions.
- [ ] Archive/closure preserves the final verified state and rejection history.
