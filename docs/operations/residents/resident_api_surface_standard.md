# Resident API Surface Standard v1

`resident-api-standard-v1` defines local-first resident interaction surfaces. Each surface reports resident identity, office/role, resident API standard version, resident implementation version, capabilities/actions, authority category, required approval level, backing implementation, status, owning office, and extension mechanism.

Capabilities are changed through reviewed Estate artifacts, not hidden UI-only code. Extension proposals may add chat behaviors, local tools, proposed actions, or behavior fields such as `interaction_profile.mood_arc`.
