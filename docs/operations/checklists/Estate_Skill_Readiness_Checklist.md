# Estate Skill Readiness Checklist

- [ ] Closed manifest validates with no unknown fields or placeholders.
- [ ] Formal name and aliases are unique and unambiguous.
- [ ] Purpose, outcome, trigger, owner, maintainer, capability and maturity are explicit.
- [ ] Provider/tool selection, bootstrap, freshness, health, worker and authority are assessed by Helen.
- [ ] Exact reads, writes, outputs, sinks, classification and bounded wildcard policy are declared.
- [ ] Ordered stages, preconditions, stop, escalation, cancel, timeout and partial behavior are tested.
- [ ] Replay/conflict, artifact, receipt, validation, reconciliation, terminal, rollback, deprecation and supersession contracts exist.
- [ ] Grace discovery/help is proposal-only; execution requires explicit authority.
- [ ] Diagnostic and execution paths remain distinct.
- [ ] Tests cover missing authority, unavailable/stale dependencies, prohibited scope, replay/conflict, and truthful gaps.
- [ ] Live evidence is bounded, secret-free, and institutional acceptance remains separate.
