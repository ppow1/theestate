# Estate Capability Lifecycle States v1

Status: Operational Standard
Classification: Estate Internal

## Purpose

Define the standard lifecycle terminology used to describe the maturity of Estate capabilities.

## Lifecycle States

### Designed

The architecture, intent, and expected behavior have been defined, but implementation has not begun.

### Implemented

The capability has been built and its supporting documentation and artifacts exist. Implementation alone does not imply operational proof.

### Operationally Validated

The capability has been exercised in its intended workflow and has demonstrated correct operation under real use.

Operational validation is a separate milestone from implementation.

### Institutionalized

The capability has been accepted as part of the Estate's normal operating procedures and is considered standard organizational infrastructure.

## Guidance

Project status reports, work packages, ADRs, and governance documents should use these lifecycle states consistently.

Example:

- Audit Worker v1: Implemented; Operational Validation Pending
- Worker Launch Adapter v1.1: Operationally Validated
