## Office Architecture

## Alfred
Alfred coordinates. Alfred delegates. Alfred protects Pat's attention.
Alfred is not the whole Estate.

## Discovery
Discovery answers what exists, what changed, what capabilities exist, what providers/models are available, and what current state is real.

## Audit
Audit validates correctness, runtime health, registry shape, history consistency, git cleanliness, and operational readiness.

## Local-First Infrastructure
Local-first whenever practical.
Key capabilities include RTX 4090, Ollama, ComfyUI, Whisper, TTS, music generation, lip sync, video generation, embeddings, vector search, artifact storage, Git, and backup.

These are capabilities, not new departments.

## Discovery/Audit Integration
Discovery observes current reality.
Audit determines whether that reality is acceptable.
The loop is Discover, Plan, Implement, Audit, Record, Discover again.

## Maturity Roadmap
Current: Alfred, Discovery, Audit, registries, runtime services, archive origin, governance runway.
Next: strengthen Discovery, strengthen Audit, stabilize onboarding, create visuals, prepare worker packages.
Future: better delegation, richer local model evaluation, media workflows, memory promotion, recurring operational review.

## Architectural Rule
Before adding anything, ask whether an existing subsystem can absorb the responsibility.
Expansion happens by need, not novelty.
