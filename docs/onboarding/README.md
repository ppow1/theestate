# Estate Onboarding

Status: Operational
Classification: Estate Internal

## Purpose

This directory contains reusable onboarding assets for Estate workers.

The onboarding package begins with visual orientation so a worker understands the Estate as an institution before reading procedural documents or starting an assignment.

## Visual Orientation

Required visual artifacts are listed in:

- `visual_manifest.md`

The actual image files live under:

- `visuals/`

## Worker Onboarding Order

1. Review the visual orientation manifest.
2. Review each visual artifact in the listed order.
3. Review Worker Runtime Contract.
4. Review Instruction Precedence.
5. Review Estate Orientation Handbook.
6. Review Estate Manual.
7. Review the assigned work package.

## Maintenance Rule

Worker launchers should read `visual_manifest.md` rather than hard-coding image filenames.
