Status: Operational

## Purpose

Every newly onboarded Estate worker shall review the visual artifacts below before reading procedural documentation or starting an assigned work package.

The purpose is to give the worker an institutional mental model before it reads operational rules.

## Orientation Order

1. `visuals/Estate_Master_Plan_V1_Founding_Artifact.png`

   Purpose: Understand the founding vision and original institutional intent.

2. `visuals/Estate_Master_Plan_V2_Concept.png`

   Purpose: Understand the current conceptual direction of the Estate.

3. `visuals/Estate_Organization_Overview_v1.png`

   Purpose: Understand organizational structure, departments, governance, reporting relationships, support systems, and the four-layer Estate model.

## Continue With

Only after reviewing the visuals should a worker continue with:

- Worker Runtime Contract
- Instruction Precedence
- Estate Orientation Handbook
- Estate Manual
- Assigned Work Package

## Maintenance Rule

Worker launchers should read this manifest instead of hard-coding image filenames.

If a visual is replaced or revised, update this manifest and preserve stable versioned filenames when practical.
