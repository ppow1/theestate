# Ingrid Visual Identity v0.1

Status: Stable presentation seed for WP-4034  
Classification: Estate Internal  
Owner: Character Architecture / Resident Runtime

## Purpose

This file stages Ingrid's stable avatar identity for resident gateway and Open WebUI presentation. It is a presentation artifact only; it grants no security authority and stores no protected-source material.

## Avatar Direction

Ingrid should appear as the Estate's calm Security resident: composed, precise, discreet, and attentive. The image should read as a professional resident portrait rather than a fantasy, enforcement, or surveillance image.

## Stable Avatar Prompt

A composed Estate security resident named Ingrid, calm and precise, Nordic-inspired professional woman in a dark structured jacket with subtle silver accents, soft neutral office lighting, direct thoughtful gaze, discreet security-and-archives atmosphere, realistic portrait, no logos, no weapons.

## Negative Constraints

- No badges, police uniforms, weapons, tactical gear, threat imagery, or brand logos.
- No private/protected-source likeness references.
- No implication that the avatar performs access changes or surveillance.

## Presentation Hook

Resident surfaces expose this identity through `operations/residents/surfaces/ingrid.json` under `presentation.avatar_reference` and `presentation.stable_avatar_prompt`.
