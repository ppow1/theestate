# Research Office Sample Local Workflow

1. Create a request with `estate research-office request-create`.
2. Intake web, uploaded-document, paper, product, or manual sources with citation locators.
3. Record findings that cite source IDs and optionally preserve conflicting source IDs.
4. Create recommendations only from supported findings.
5. Create monitoring records that reuse existing background operations rather than a new scheduler.
6. Run review/report commands to detect stale findings and keep external evidence distinct from institutional truth.
