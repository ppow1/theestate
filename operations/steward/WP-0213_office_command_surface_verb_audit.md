# WP-0213 Office Command Surface Verb Audit

## Scope
WP-0213 converts the first Office areas from noun/status views into governed local verbs. Every available control below dispatches through `estate.core.office_command_surface.execute_office_action` and returns `completed`, `queued`, `blocked`, or `failed`.

| Tab ID | Current visible nouns/status sections | Meaningful Steward verbs | WP-0213 implemented verbs | Gated/unavailable verbs | Deferred verbs and reason | Local handler used | Artifacts/runtime state affected | Steward-visible outcome |
|---|---|---|---|---|---|---|---|---|
| `ai-services-models` | service/model dashboard, model inventory, approvals, audit tail | refresh discovery, sync provider inventory, inspect status, start/stop/load services | Refresh local AI service inventory | Start/stop/load AI service: gated because Office process-control approval workflow is not implemented | service lifecycle controls until governed approval/process control exists | `refresh_ai_services` -> `generate_service_status_board`, `sync_ollama_providers` | `runtime/services/service_status_board.json`, `operations/services/service_status_board.md`, `data/registry/providers.json` | JSON result panel shows completed/failed/blocked plus artifacts |
| `validation` | validation health checks and validation status artifact | run production readiness, validate package, export evidence | Run production readiness refresh | none in first surface | evidence bundle export deferred to a later evidence packaging verb | `run_production_readiness` -> `generate_production_readiness_report` | `runtime/validation/production_readiness.json`, `operations/validation/production_readiness.md` | result warns evidence is not institutional acceptance |

## Changed controls
Every control introduced by WP-0213 is rendered by `_office_action_controls_html` and bound by `bindOfficeActions`/`runOfficeAction` in the Office HTML runtime. Static file mode deterministically reports `blocked` because POSTing to local handlers requires served local mode. Served mode posts to `/api/office/actions/execute`.
