# Review Cadence

Status: Active
Owner: Alfred / Chief of Staff
Classification: Estate Internal
Updated: 2026-06-30

## Purpose

The Review Cadence defines the lightweight operating rhythm for the Estate Operations Board.

The cadence should reduce Steward burden, not create ceremony.

## Daily Review

Recommended owner: Alfred / Chief of Staff

Recommended duration: under 5 minutes

Questions:

- What is active today?
- What is blocked?
- What is waiting?
- What requires review?
- What changed since yesterday?

Output:

- Update Daily Task Board.
- Move completed items to Completed Today.
- Escalate only true blockers or Steward-required decisions.

## Weekly Planning

Recommended owner: Alfred / Chief of Staff with Chief Architect input

Recommended duration: under 20 minutes

Questions:

- Which active efforts should continue?
- Which waiting items should resume or close?
- Which Parking Lot items should be reconsidered?
- Are any deferred ideas ready to become active work?
- Are there recurring manual updates that should be considered for automation?

Output:

- Update Active Work Board.
- Review Parking Lot.
- Refresh Roadmap if a milestone changed.

## Milestone Review

Recommended trigger: capability milestone complete, major EC change, or strategic handoff

Questions:

- Did the work satisfy its mission?
- Did it strengthen an existing institution?
- Did it create unnecessary bureaucracy?
- Should Audit or Discovery add validation?
- Should Alfred automate any part of the pattern?

Output:

- Update roadmap milestone.
- Record follow-up work.
- Add only stable repeated patterns to automation candidates.

## Quarterly Architectural Review

Recommended owner: Chief Architect

Questions:

- Are Estate institutions still correctly shaped?
- Is the Collaboration Layer still transport-independent?
- Is the Operations Board still lightweight?
- Is Steward cognitive burden actually lower?
- Which architectural assumptions should be preserved, revised, or retired?

Output:

- Architecture notes.
- Parking Lot review.
- Roadmap adjustment.
- Governance update only when justified.
