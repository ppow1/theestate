# Proposed Onboarding Lessons Learned

Status: Proposed

This document captures operational conventions discovered during real Estate work that should be considered for inclusion in the canonical onboarding handbook.

## Lessons

1. User-pasted artifacts are review requests by default.
2. Distinguish Audit from Validation.
3. Validation should produce executable PowerShell command sequences using Estate formatting conventions.
4. The Work Package is the contract; the Codex handoff should simply reference the work package and say "Read <path>. Do exactly what it says."
5. A GitHub merge is not validation.
6. Screenshots and logs usually represent engineering state transitions and should be audited automatically.
7. Prefer institutional simplification and standardization.
8. Follow the engineering sequence: Discussion → Decision → Work Package → Handoff → Implementation → Audit → Validation.
9. Learn and document Steward operating conventions as institutional knowledge.
10. Capture recurring conventions in the Parking Lot until promoted.
