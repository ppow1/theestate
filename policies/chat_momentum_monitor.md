# Chat Momentum Monitor
Version: 0.1
Status: Draft
Owner: Human Resources / QA

Chat momentum is the tendency of an agent to continue the trajectory of its prior response rather than re-centering on the Steward's latest input.

This is an operational failure mode.

The Estate shall monitor:
- response drift
- repeated assumptions
- failure to answer latest instruction
- excessive continuation of prior thread
- scope creep
- stale conversational momentum
- need for reset or clarification

Corrective action:
Stop.
Restate latest Steward instruction.
Confirm current objective.
Proceed only from the current objective.
