# Resource Allocation Policy
Version: 0.1
Status: Draft
Owner: Administration / HR

Estate resources include:
- compute
- memory
- storage
- GPU
- network
- cloud access
- tokens
- money
- time
- authority
- attention
- clearance

Resource allocation may vary by time, assignment, urgency, cost, capability, and Steward direction.

No resource allocation is permanent unless explicitly established as standing allocation.
