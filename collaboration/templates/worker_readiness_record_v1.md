## Purpose

This template records whether a worker has completed required Estate orientation before beginning assigned work.

It is not primarily a punishment record. It is an institutional readiness record.

For AI workers, the record validates state: what the worker was told, which onboarding version was used, what visual artifacts were reviewed, what escalation path was provided, and what assignment was accepted.

For AI HR, the record supports workforce quality review. If a worker fails after completing orientation, the Estate can determine whether the worker ignored guidance or whether the onboarding material itself needs improvement.

## Metrics Notes

If the worker later fails to follow documented instructions, AI HR may compare the failure against this readiness record.

This should be used to improve the institution first and evaluate the worker second.

Possible outcomes:

- Worker ignored explicit guidance.
- Worker lacked required orientation.
- Orientation material was insufficient.
- Work package was unclear.
- Escalation path failed.
- Architecture was not mature enough.
- Assignment exceeded worker capability.

## Final Statement

The worker is cleared to begin only when the assigned coordinator determines that required orientation is complete enough for the work package scope.
