# WP-4233 — Grace runtime tool bridge

This work package registers an Open WebUI Tool and Grace-only grounding filter. Read operations call the authenticated loopback `LoopbackGraceMomentumClient` boundary; assignment execution remains behind the resident gateway's approved local-workflow path and is never exposed as an arbitrary Open WebUI mutation tool.

The approved production path creates authoritative assignment, Dispatch, progress, completion/failure, and artifact records and invokes only the admitted loopback `comfyui.local.image` adapter.

The Estate resident catalog associates `grace_runtime_bridge` and `grace_runtime_grounding` only with `estate/grace` through `info.meta.toolIds` and `filterIds`.
