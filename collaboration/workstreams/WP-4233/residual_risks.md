# Residual risks

- Production image execution requires the runtime to be started in `governed_local_test` mode and the ComfyUI adapter to be explicitly admitted; the default runtime mode remains shadow and fails closed until deployment enables the approved path.
- The exact Open WebUI API transcript is validated with the live authenticated Open WebUI service; a browser-rendered transcript is not required for the reproducible acceptance procedure.
- The bridge's exact runtime claims depend on the existing Grace Momentum issuer and active claims boundary.
