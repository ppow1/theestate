# Campaign Capability Inventory

`capability_inventory.json` is normative. It covers every numerical package WP-4214 through WP-4228 and separately represents duplicate identities. `authored_only` means no production claim; `partially_integrated` means useful staged/runtime pieces exist without complete canonical wiring; `production_advisory` and `production_read_only` explicitly deny action authority; `production_action_capable` still requires governed transitions.
