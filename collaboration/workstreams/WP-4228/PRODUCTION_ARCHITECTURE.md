# Production Architecture

Authoritative evidence enters deterministic reconciliation. Recommendations reference its content hash and carry confidence. A recognized authority records an append-only decision. Only an accepted, hash-matching recommendation may translate to a proposed Grace objective, Engineering work item, or Helen capability request. Execution requires separate capability, commission, authorization, Dispatch, validation, and receipt records. Replay and inspection are read-only. JSONL hash chaining makes tampering visible; idempotency keys make retries stable.
