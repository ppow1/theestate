# Evelyn Canon Program — Work in Progress

**Status:** IN PROCESS

**Execution state:** Active workstream; current campaign record updated; broader expansion paused pending return

## 1. Purpose

This workstream preserves the current direction, campaign breakdown, operating history, output locations, and future expansion ideas for the Evelyn visual canon.

The purpose is not merely to generate images. It is to build a versioned, reviewable canon corpus that can support:

- visual consistency across future Evelyn outputs;
- benchmark comparison across models, workflows, prompts, and settings;
- reference material for face, neck, body, limbs, posture, movement, clothing, hair, lighting, camera, and environment;
- repeatable campaign execution;
- traceable relationships between prompts, workflows, outputs, manifests, ledgers, and approved canon assets;
- future Estate integration without losing the history of the current local file layout.

This is an active work-in-progress project, not a parking-lot item.

## 2. Program concept

The Evelyn effort should be treated as a **Canon Development Program** made up of bounded campaigns.

Each campaign should leave behind:

- a campaign identity and name;
- purpose and scope;
- expected runtime and resource assumptions;
- prompt or input catalog;
- workflow version;
- output path;
- manifest and ledger path;
- success, failure, skip, and retry evidence;
- notes on what changed in the canon;
- known defects and follow-up work;
- links to any promoted canon assets.

The program notebook is intended to become the durable index into the corpus.

Verification should include:

- expected file count;
- actual file count;
- zero-byte and unreadable-file checks;
- duplicate detection where practical;
- manifest and ledger consistency;
- failed and skipped jobs;
- workflow and prompt provenance;
- visual review status;
- canon-promotion status;
- known defects;
- whether the output path has been recorded and verified.

Local execution success, visual quality acceptance, and canon promotion are separate decisions.
