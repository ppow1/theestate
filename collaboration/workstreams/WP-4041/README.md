# WP-4041 Resident Identity Package Standard

This workstream defines a staged, provider-independent Resident Identity Package (RIP) v1. It is a standards package only; it does not install loaders, activate residents, change routing, edit registries, or modify Open WebUI.

## Contents

- `Resident_Identity_Package_Standard_v1.md` — normative contract.
- `schemas/` — JSON schemas for identity packages, presentation bindings, and relationship profiles.
- `templates/` — authoring templates for package sections and supporting artifacts.
- `examples/` — validating example packages for Alfred, Helen, Grace, Ingrid, and Evelyn.
- `tests/` — focused validation tests for the standard.
- `install_manifest.json` — handoff manifest for WP-4042.
- `notes/` — integration and rollback notes.
