# WP-0200 Office Action Registry Notes

The staged registry uses one shared vocabulary for Office Wave 1: action IDs, labels, target tabs, action classes, authority classes, confirmation requirements, local-only posture, read/write artifacts, command hooks, output paths, validation commands, failure behavior, audit expectation, and disabled reasons.

Authority classes are: safe read-only; safe local generated-artifact update; Steward-confirmed local mutation; authority-gated institutional action; prohibited until future governance/tooling exists. Copy-command hooks are non-executable by default; execution requires a future authorized install package.
