# 28. Permitted Review Outcomes

## 28.1 Select A, B, or C

The Steward selects one candidate for canonical-promotion review.

## 28.2 No meaningful difference

Used only when:

- 

the comparison is technically valid;

- 

the differences are genuinely negligible;

- 

legibility was sufficient to reach that conclusion.

It must not be used when the sheet itself failed.

## 28.3 None fit the resident

All variants are rejected.

A new range is required.

## 28.4 Narrow the range

The preferred result lies between two candidates.

Example:

```

```
A = 20
B = 21
C = 22

Steward direction:
Review 20.5, 21.0, and 21.5.
```

```

## 28.5 Widen the range

The variants are too similar to establish direction.

## 28.6 Isolate variables

A combined bust-waist-hip comparison proves too difficult to interpret.

The next cycle tests each dimension separately.

## 28.7 Defer

The Steward may defer because:

- 

facial identity is unstable;

- 

wardrobe is unresolved;

- 

height is unresolved;

- 

another dependency must be completed first.

# 30. Rejected-Evidence Handling

Rejected variants must retain:

- 

exact measurements;

- 

images;

- 

prompts;

- 

seeds;

- 

model data;

- 

reason for rejection;

- 

Steward notes;

- 

comparison-set linkage;

- 

date;

- 

review outcome.

Rejected variants must not:

- 

appear as current canon;

- 

be silently reused in later generations;

- 

be deleted solely because they were rejected;

- 

be used to challenge canon without contextualizing the decision.

# 31. Supersession

A later comparison may supersede an earlier one when:

- 

better controls are used;

- 

the resident’s face is more stable;

- 

the measurement range changes;

- 

new Steward direction exists;

- 

an earlier legibility failure is corrected;

- 

an approved physical specification has changed.

Supersession does not erase the earlier decision history.
