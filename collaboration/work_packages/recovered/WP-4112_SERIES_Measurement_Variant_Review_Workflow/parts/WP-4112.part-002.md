# 12. Seed and Generation Policy

## 12.1 Seed reuse

Where the generation system supports it, the same seed should be used across variants.

The purpose is to reduce unrelated variation.

## 12.2 Seed limitation

The same seed does not guarantee identical:

- 

face;

- 

pose;

- 

clothing behavior;

- 

anatomy;

- 

image composition.

Therefore seed equality is necessary evidence, not sufficient proof of control.

## 12.3 Deterministic workflow

The implementation should preserve:

- 

seed;

- 

model hash;

- 

LoRA versions;

- 

workflow hash;

- 

prompt;

negative prompt;

ControlNet input;

- 

pose input;

- 

sampler;

scheduler;

resolution;

denoise;

- 

postprocessing;

- 

upscaling;

- 

revision chain.

## 12.4 Controlled rerender

A rerender must distinguish:

- 

same plan, new generation attempt;

- 

altered measurement spread;

- 

altered layout;

- 

altered wardrobe;

- 

altered camera;

- 

new comparison cycle.

Materially altered comparison conditions require a new comparison-set version.

# 13. Wardrobe Standard

The review wardrobe must make proportion differences visible without becoming explicit.

## 13.1 Neutral wardrobe

Suitable for broad review where body shape need not be strongly emphasized.

Characteristics:

- 

clean silhouette;

- 

minimal ornament;

- 

stable fabric;

- 

no oversized layers;

- 

no heavy draping;

- 

no bulky outerwear.

## 13.2 Fitted wardrobe

Suitable for waist, torso, shoulder, and general build review.

Characteristics:

- 

body-following but non-explicit;

- 

stable neckline;

- 

predictable seam placement;

- 

controlled stretch;

- 

clear waist and shoulder definition.

## 13.3 Silhouette-revealing wardrobe

Suitable for subtle proportion review.

Characteristics:

- 

opaque;

- 

non-explicit;

- 

appropriate to an adult resident;

- 

enough contour visibility to judge the selected variables;

- 

no distracting pattern;

- 

no garment construction that artificially creates the tested difference.

## 13.4 Wardrobe prohibitions

Prohibited comparison clothing includes:

- 

oversized garments;

- 

heavy coats;

- 

extreme padding;

- 

uncontrolled compression;

- 

loose draping;

- 

high-volume ruffles;

- 

asymmetric layers;

- 

clothing that changes between variants;

- 

explicit attire.

# 16. Turnaround Standard

Each variant should receive the same ordered five-angle turnaround:

- 

front;

- 

front three-quarter;

- 

side;

- 

rear three-quarter;

- 

rear.

This order is specified in the work package.

## 16.1 Turnaround constraints

Each angle must preserve:

- 

equivalent camera distance;

- 

equivalent camera height;

- 

equivalent focal length;

- 

equivalent subject scale;

- 

equivalent floor position;

- 

equivalent pose family;

- 

equivalent expression;

- 

equivalent wardrobe;

- 

equivalent lighting;

- 

equivalent background.

## 16.2 Side-view importance

The side view is required because front-view differences may obscure:

- 

torso projection;

- 

hip projection;

- 

bust or chest projection;

- 

posture contamination;

- 

abdominal contour;

- 

pelvic tilt.

## 16.3 Rear-view importance

The rear view is required because:

- 

shoulder width;

- 

waist taper;

- 

hip width;

- 

leg alignment;

- 

garment fit;

may differ from the front read.
