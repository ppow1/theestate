# 9. Three-Variant Standard

## 9.1 Variant A

Represents the bounded lower option.

Possible meanings:

- 

narrower;

- 

smaller;

- 

shorter;

- 

less pronounced;

- 

lighter build;

- 

lower measurement.

## 9.2 Variant B

Represents:

- 

current baseline;

- 

provisional center;

- 

most likely candidate;

- 

prior working specification.

## 9.3 Variant C

Represents the bounded upper option.

Possible meanings:

- 

fuller;

- 

broader;

- 

longer;

- 

more pronounced;

- 

heavier build;

- 

higher measurement.

## 9.4 Label discipline

Labels must remain neutral.

Prohibited labels include:

- 

best;

- 

ideal;

- 

attractive;

- 

too small;

- 

too large;

- 

correct;

- 

wrong.

Those judgments belong in the review record, not in preloaded variant names.
