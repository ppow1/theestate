# 17. Controlled Full-Body Reference Standard

Each resident must receive:

- 

neutral front;

- 

neutral profile;

- 

neutral rear;

- 

front three-quarter;

- 

rear three-quarter;

- 

applicable 3-inch-or-greater heel reference;

- 

standardized seated reference;

- 

desk or doorway reference;

- 

pair or group comparison;

- 

annotated scale sheet.

These required assets are specified directly by WP-4111.

## 17.1 Front reference

Must show:

- 

level floor;

- 

full head;

- 

full feet;

- 

neutral stance;

- 

minimal perspective distortion;

- 

visible shoulder, waist, hip, knee, and ankle landmarks.

## 17.2 Profile reference

Must show:

- 

true side orientation;

- 

no torso rotation;

- 

heel contact;

- 

head neutral;

- 

clear spinal and pelvic posture.

## 17.3 Rear reference

Must show:

- 

level shoulders;

- 

centered stance;

- 

visible heel contact;

- 

no hidden knee bend.

## 17.4 Three-quarter references

Must retain the same camera geometry and body scale as the neutral views.
