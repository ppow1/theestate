# 32. Decision Logic

## 32.1 Canonical scale-asset eligibility

```

```

```

```

## 32.2 Automatic blocking conditions

Block canonicalization when:

- 

camera conditions are missing;

- 

footwear height is missing;

- 

metric and imperial height conflict;

- 

floor plane is incoherent;

- 

full feet or head are cropped in a required full-body reference;

- 

relative-height order is reversed;

- 

environment dimensions are unknown;

- 

the resident has been independently resized;

- 

posture hides a scale error;

- 

heels are written into canonical height;

- 

scale failure lacks a regeneration record.

## 32.3 Escalation levels

### Level 0 — Metadata correction

Label, unit, or nonmaterial annotation issue.

### Level 1 — Comparison-control failure

Camera, crop, or alignment mismatch.

### Level 2 — Material proportion failure

Height, torso, leg, or waist placement drift.

### Level 3 — Multi-resident scale conflict

Relative-height ordering or shared floor-plane failure.

### Level 4 — Canonical integrity failure

True height overwritten, conflicting active scale canon, or repeated silent acceptance of failed assets.
