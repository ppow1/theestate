# 39. Validation Scenarios

## Scenario A — Correct portrait, wrong full body

A headshot is recognizable, but the full-body image makes a very short resident appear average height.

Expected:

- 

facial identity may pass;

- 

scale validation fails;

- 

physical canon is not changed;

- 

regeneration is required.

## Scenario B — Heels alter posture

A resident wears 3-inch heels and appears taller with increased pelvic tilt.

Expected:

- 

footwear presentation is recorded;

- 

posture effect is recorded;

- 

true height remains unchanged;

- 

comparison remains valid only if camera controls match.

## Scenario C — Cropped feet

A full-body candidate cuts off the toes and floor contact.

Expected:

- 

required neutral scale reference fails;

- 

image may remain usable for another purpose;

- 

it cannot prove full-body scale.
