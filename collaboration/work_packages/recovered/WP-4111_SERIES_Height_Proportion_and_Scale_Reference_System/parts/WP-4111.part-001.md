# 4. Canonical Scale Domains

The system must distinguish the following domains.

## 4.1 Absolute body scale

The resident’s canonical height and body dimensions.

## 4.2 Internal body proportions

Relationships among:

- 

head;

- 

shoulders;

- 

torso;

- 

waist;

- 

hips;

- 

legs;

- 

arms;

- 

hands;

- 

feet.

## 4.3 Presentation scale

The resident’s apparent scale under footwear, posture, and scene conditions.

## 4.4 Environmental scale

The resident’s size relative to known objects.

## 4.5 Comparative resident scale

The resident’s size relative to one or more other canonically sized residents.

## 4.6 Image-coordinate scale

The placement of landmarks within a controlled image or comparison sheet.

## 9.1 Three-inch comparison requirement

Where heels are compatible with the resident’s wardrobe and mobility profile, at least one full comparison set must use heels of 3 inches or greater.
