## Integration controls

- Branches: `codex/prod-ptm-001a-*`, `codex/prod-ptm-001b-*`, and
  `codex/prod-ptm-001c-*`; integration branch `integration/ptm-prod-01`.
- `PROD-PTM-001A` freezes the adapter interface at Gate G1.
- Later packages must not amend that interface independently. A required change
  produces a stop/replan record reviewed by the Chief Architect.
- No package may write authoritative sources, create persistent canonical events,
  or implement Phase 2 ledger behavior.
- Package completion, merge approval, campaign validation, and institutional
  acceptance remain distinct decisions with distinct evidence.

## Campaign validation

- canonical verifier JSON is a PASS and attached to launch evidence;
- package-specific tests and the registered repository test suite pass;
- an instrumented test proves source adapters perform no writes;
- fixtures prove missing, malformed, conflicting, and stale sources remain
  explicit rather than guessed;
- repeated pilot builds are byte-equivalent after volatile report metadata is
  normalized;
- every projected field traces to source references and hashes;
- security review confirms allowlisted paths, bounded file sizes, and no secret
  or private payload leakage;
- `git diff --check` passes.
