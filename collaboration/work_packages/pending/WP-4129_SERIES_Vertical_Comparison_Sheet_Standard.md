# WP-4129 — Vertical Comparison Sheet Standard

**Series:** Visual Estate Initiative — Campaign 03

**Status:** Pending

## Objective

Define a comparison-sheet layout that makes subtle differences between resident measurement variants easy to inspect without opening multiple browser windows or mentally reconstructing earlier renders.

## Core Rule

Measurement variants must be presented in vertically stacked, angle-aligned comparison sheets. The layout must allow the Steward to compare the same angle across variants with minimal eye movement.

## Required Layout

For each resident review set:

- Variant A occupies the first complete row or section.
- Variant B occupies the second complete row or section.
- Variant C occupies the third complete row or section.
- Every variant uses the same ordered angle sequence.
- Corresponding angles align on a shared visual grid.

Preferred angle order:

1. front
2. front 45°
3. profile
4. rear 45°
5. rear

The full eight-angle set may be used when canvas dimensions permit clear inspection.

## Comparison Controls

Across all variants, hold constant:

- face and identity seed or reference
- age presentation
- hairstyle
- expression
- camera geometry
- lighting
- pose
- wardrobe
- fabric behavior
- footwear
- background
- image scale
- crop

Only the declared measurement or proportion variables may change.

## Heel Requirement

At least one applicable comparison sheet per resident must use footwear with a heel height of 3 inches or greater. The exact heel height must be labeled. Heel-based comparison must not replace a neutral footwear or barefoot-equivalent scale reference when that reference is needed for true height evaluation.

## Labels

Every sheet must clearly display:

- resident name
- review date
- variant identifier
- exact declared measurements
- height
- footwear and heel height
- wardrobe identifier
- model and workflow identifier
- seed or reproducibility metadata when available
- review status

## Visibility Standard

The comparison has failed when the intended difference cannot be reasonably inspected at normal display size. If the Steward must open separate browser windows, repeatedly zoom, or rely on memory to see the change, regenerate or redesign the sheet.

Permitted remedies include:

- increasing canvas resolution
- reducing unrelated decorative content
- enlarging full-body figures
- using clearer alignment guides
- adding silhouette overlays
- adding localized crop comparisons while retaining the complete figures

## Deliverables

1. Standard portrait and landscape templates.
2. A tall-format vertical template optimized for three variants.
3. Angle-alignment guides.
4. Label and metadata rules.
5. Export presets for browser review and archival review.
6. A comparison-readability validation checklist.

## Dependencies

- WP-4112
- WP-4116
- WP-4128

## Acceptance Criteria

- Three nearby variants can be compared on one review surface.
- Same-angle views are visibly aligned.
- At least one 3-inch-or-higher heel presentation is supported and labeled.
- Differences remain inspectable without external window arrangement.
- Decorative layout never takes priority over comparison clarity.
- The template supports resident-specific flexibility rather than forcing Evelyn's narrow calibration range onto every resident.
