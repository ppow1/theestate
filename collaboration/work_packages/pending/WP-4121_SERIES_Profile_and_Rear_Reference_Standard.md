# WP-4121 — Profile and Rear Reference Standard

## Status
Pending

## Series
Visual Estate Initiative — Campaign 02: Canonical Portrait Library

## Objective
Define and implement a controlled profile and rear-reference standard so each resident remains visually coherent from angles that hero portraits rarely prove.

## Dependencies
- WP-4108 Visual Bible Schema and Repository Structure
- WP-4109 Canonical Physical Specification Standard
- WP-4110 Facial Geometry and Visual Fingerprint
- WP-4111 Height, Proportion, and Scale Reference System
- WP-4113 Wardrobe and Signature Look Library
- WP-4114 Visual Prompt Engineering Canon
- WP-4115 Visual Negative Prompt Canon
- WP-4120 Full-Body Reference Library

## Scope
For each resident, define and produce reviewable references covering:

1. Left facial profile.
2. Right facial profile.
3. Left full-body profile.
4. Right full-body profile.
5. Rear head-and-shoulders reference.
6. Rear full-body reference.
7. Rear three-quarter left.
8. Rear three-quarter right.
9. Hair fall and silhouette from behind.
10. Posture and shoulder-line reference.

## Standardization Requirements
- Use matched camera height, focal length, lighting, expression, wardrobe, and pose wherever direct comparison is intended.
- Preserve canonical nose, chin, jaw, forehead, neck, shoulder, waist, hip, and leg geometry.
- Ensure left and right profiles describe the same person rather than mirrored approximations with identity drift.
- Document natural asymmetries when they are intentional and canonical.
- Rear references must preserve hair length, density, texture, part, and movement.
- Clothing seams, hems, closures, footwear, and accessories must remain physically plausible and consistent.
- Do not overemphasize anatomy or sexualize rear references; these are artist and continuity references.
- Keep private or restricted wardrobe variants in their proper governed layer.

## Deliverables
- Per-resident profile and rear-reference asset slots.
- Matched-angle comparison sheets.
- Facial profile geometry notes.
- Hair-from-behind reference notes.
- Posture and shoulder-line notes.
- Prompt templates for profile and rear views.
- Negative prompts addressing mirrored text, facial drift, hair inconsistency, malformed ears, duplicate limbs, distorted hands, and clothing discontinuity.
- Steward review checklist and revision notes.

## Repository Targets
Store references within the resident Visual Bible and asset-library structure established by WP-4108. Separate review candidates, rejected assets, and canonical assets.

## Acceptance Criteria
- Every active resident has left, right, and rear reference categories represented or explicitly marked pending generation.
- Profile and rear images remain recognizably the same resident as the approved hero and office portraits.
- Hair, posture, stature, wardrobe, and proportions remain consistent across matched views.
- Both sides of the face are documented without unapproved symmetry normalization.
- Rear references are useful for later 360-degree and group-scene generation.
- Steward review can approve each angle independently.

## Non-Goals
- This package does not create the complete 360-degree comparison workflow.
- This package does not select final measurement variants.
- This package does not replace Campaign 03 turnaround validation.

## Completion Condition
The Estate has a reliable profile-and-rear reference standard that proves each resident’s identity beyond the front-facing portrait and supports later turnaround, wardrobe, animation, and group-scene work.
