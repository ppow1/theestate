# WP-4124 — Headshot and Thumbnail Library

**Series:** Visual Estate Initiative
**Campaign:** 02 — Canonical Portrait Library
**Status:** Pending
**Execution mode:** Series

## Objective

Establish a complete, reproducible headshot and thumbnail asset library for every resident so the same canonical identity remains recognizable across profile cards, Open WebUI model lists, notifications, contact surfaces, roster views, dashboards, and other small-format interfaces.

## Scope

For each resident, define and produce:

- canonical close headshot
- shoulders-up professional headshot
- conversational headshot
- circular crop
- square crop
- transparent-background portrait cutout where technically supported
- dark-interface thumbnail
- light-interface thumbnail
- monochrome/black-and-white reference
- notification-size avatar

## Required Sizes

At minimum:

- 32 × 32
- 64 × 64
- 128 × 128
- 256 × 256
- 512 × 512 master crop

All derivatives must trace to a higher-resolution canonical source rather than being independently regenerated whenever possible.

## Identity Requirements

Every thumbnail must preserve the resident’s:

- facial geometry
- eye color and shape
- hair color, texture, and silhouette
- age impression
- visual fingerprint
- signature expression or role-appropriate neutral expression
- approved wardrobe cues where visible

Residents must remain distinguishable at 32 × 32 without captions when displayed together.

## Composition Standard

Use consistent:

- camera height
- focal length range suitable for portrait work
- neutral perspective without wide-angle distortion
- face scale within frame
- eye-line position
- crop margins
- lighting direction
- background simplicity

Avoid over-tight crops that remove the hair silhouette or jawline cues needed for recognition.

## Expression Set

At least three approved headshot expressions per resident:

1. canonical neutral
2. warm/conversational
3. role-specific expression

The role-specific expression must come from WP-4123 and remain natural rather than theatrical.

## Thumbnail QA

Validate each asset at native display size, not only enlarged.

Reject assets with:

- identity drift
- lost eye color
- face-shape distortion
- hair-shape collapse
- excessive beauty-filter smoothing
- unreadable dark-mode or light-mode contrast
- crop inconsistency
- duplicate-looking residents
- artifacts that become more prominent when reduced

## Deliverables

- per-resident master headshot set
- size derivatives
- crop metadata
- source-image provenance
- interface-preview sheet showing all residents together
- dark-mode and light-mode preview sheets
- recognition test report
- Steward review notes

## Repository Targets

Use the Visual Bible and asset-library structure established by WP-4108. Store canonical masters separately from generated derivatives and review-only candidates.

## Acceptance Criteria

This work package is complete when:

- every commissioned resident has the full headshot set
- all required sizes exist
- the 32 × 32 set remains distinguishable without labels
- dark and light interface previews pass review
- every derivative links to its canonical source
- Steward comments and selected canonical assets are recorded
- no review candidate is promoted without explicit canonical status

## Completion Condition

The Estate has a consistent, recognizable, production-ready resident avatar system from high-resolution portrait source through the smallest supported interface thumbnail.
