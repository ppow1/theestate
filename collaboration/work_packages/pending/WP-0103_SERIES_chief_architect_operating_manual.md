# SERIES TASK WP-0103 — Chief Architect Operating Manual

## Codex Command
Read `collaboration/work_packages/pending/WP-0103_SERIES_chief_architect_operating_manual.md` and do exactly what it says.

## Mission
Produce the first edition of the Chief Architect Operating Manual: a durable institutional manual describing how a Chief Architect performs the role, not merely how to complete an individual work package.

## Background
Successive Chief Architects have developed conventions through practice rather than through a single operational reference. The Estate has now reached a level of maturity where the Office of Chief Architect should have its own operating manual.

This manual is intended to onboard future occupants of the Office while preserving institutional continuity. It should consolidate lessons learned from Chief Architects #1 through #4 without replacing constitutional documents.

## Scope
Create a durable manual that explains:
- the purpose of the Office of Chief Architect
- relationship to the Steward, Chief Architect peers, Codex, Validation, and Estate governance
- architectural responsibilities
- work package lifecycle
- how to author work packages
- where the current Codex Task Template Standard lives and how it must be used
- required work package sections
- numbering and reservation practices
- interaction with validation
- architectural review expectations
- backlog management philosophy
- succession and handoff expectations
- common pitfalls and anti-patterns
- document maintenance expectations

## Out of Scope
Do not rewrite the Constitution, Governance, Estate Manual, or Validation Manual.

Do not redefine institutional authority.

## Required Behavior
The manual should be written as a standing operational reference rather than onboarding notes for one individual.

It should distinguish:
- Office vs Occupant
- Authored vs Implemented vs Validated vs Institutionalized
- Architecture vs Implementation vs Validation

Reference existing canonical documents instead of duplicating them.

## Required Artifacts
Create a durable document in the appropriate operations or governance documentation location using existing repository conventions.

## Tests
Verify the manual references current repository standards, including the Codex Task Template Standard, and can be used to onboard a future Chief Architect without relying on chat history.
