# WP-4108 — Visual Bible Schema and Repository Structure

## Classification
Series work package — Campaign 01: Visual Bible Foundation

## Objective
Create the canonical repository structure and machine-readable schema for resident Visual Bibles and their linked visual asset libraries.

## Scope
- Define a versioned Visual Bible schema for each resident.
- Define repository paths for specifications, generated assets, review candidates, rejected assets, approved canonical assets, prompts, negative prompts, comparison sheets, 360 turnarounds, icons, group photographs, and Steward notes.
- Separate public, internal, restricted, and private visual layers.
- Preserve provenance for every generated or imported asset.
- Link each asset to resident identity, generation settings, model/provider, source references, review state, and canonical status.
