
Estate Collaboration Layer

This folder is the initial repository-based collaboration surface.

It supports the Estate Communication Bus v1 using Git, Markdown, JSON, and filesystem state.

GitHub may mirror this folder after promotion approval.

GitHub is not the Communication Bus. It is the first shared transport adapter.

Folders
messages: message lifecycle queues.
work_packages: assignable work.
promotions: boundary approval records.
status: worker and system status.
templates: reusable message templates.
Boundary Rule

Do not place Local Only material here unless it has been intentionally promoted.

Local-only material belongs under:

runtime/collaboration/local_only
